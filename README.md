# Travel Fare Calculator

## Description
This program calculates the total travel fare based on the distance traveled and the number of passengers.

## Version 1
- Input: Accepts a passenger's name, the distance traveled (in km), and the number of passengers.
- Process: Multiplies the distance by the fixed fare rate (PHP 14 per km) and by the number of passengers to get the total fare.
- Output: Passenger name and total fare in PHP, rounded to two decimal places.
- Does not include input validation.
